# CloudPulse

Team feedback portal built with Next.js and Tailwind CSS.

## Architecture

![CloudPulse Architecture](CloudPulse%20Architecture.png)

## Local Development

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment on AWS Amplify

1. Connect your GitHub repository to AWS Amplify Hosting.
2. Select the repository and main branch.
3. Accept the default build settings and click deploy.
